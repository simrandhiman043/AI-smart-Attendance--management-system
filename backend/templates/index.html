ABOUT OUR PROJECT

Making Attendance Management Smarter

This project is developed as a college project to simplify attendance management for students and teachers. It reduces manual work, keeps digital records organized, and provides useful attendance insights.

The system is built with an AI assistant that answers attendance-related queries using the Gemini API.
