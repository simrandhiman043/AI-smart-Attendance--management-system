Why Use This System?

Traditional attendance methods take time and can lead to errors. Our AI Smart Attendance Management System helps schools and colleges save time by automating the attendance process, reducing manual work, and keeping accurate digital records for both students and teachers.

  • Easy and quick attendance marking
  • Separate login for students and teachers
  • Digital records that are easy to access
  • Reduces manual paperwork

About the Project

This project is developed as a college mini project using Flask for the backend, MySQL for the database, and HTML, CSS and JavaScript for the frontend. It aims to demonstrate how a simple web application can help automate everyday college tasks like attendance management.The AI assistant will answer attendance-related queries using the Gemini API.
