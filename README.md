# AI Smart Attendance Management System

## Project Description
AI Smart Attendance Management System is a web-based application designed to simplify attendance management for educational institutions. It allows teachers to manage attendance efficiently while enabling students to track their attendance records. The system also includes an AI-powered assistant that can answer attendance-related queries and provide personalized insights.

## Features
- Student Login
- Teacher Login
- Student Registration
- Mark Attendance
- View Attendance Records
- Attendance Percentage Calculation
- Low Attendance Alerts
- Attendance Reports
- AI Attendance Assistant (Gemini API)
